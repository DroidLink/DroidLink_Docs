# Start Here with DroidLink

DroidLink is a wireless control system for Astromech droids. Use the steps
below to choose the correct hardware, obtain a license, install the firmware,
and complete setup.

## 1. Choose your DroidLink hardware

Start with the [DroidLink Main Hardware](DroidLink_Parts_List.md) guide. It
shows the supported Master, Watch Display, and Slave controller boards,
breakout boards, RC equipment, and optional Master audio hardware.

Check the photos and compatibility notes before ordering. Similar-looking
ESP32 boards are not always interchangeable.

## 2. Get a DroidLink license

A DroidLink license is required to download firmware through the Web
Installer. A license is $80 per droid. To purchase a license, email
[droidlink77@gmail.com](mailto:droidlink77@gmail.com?subject=DroidLink%20License).
In the email, say whether you also want a DroidLink DFPlayer breakout board.

## 3. Install the firmware

When the hardware and license key are ready, open the
[DroidLink Web Installer](https://droidlink.github.io/DroidLink_Installer/)
using Google Chrome or Microsoft Edge on a computer with a USB data cable.

Select the firmware entry that exactly matches the connected controller board.
In particular, DroidLink Slave has separate Installer choices for the ESP32-C3
Super Mini and ESP32 DevKit.

## 4. Complete setup

Follow [Getting Started with DroidLink](getting_started.md) to activate the
Master, configure the required Watch Display, add Slave and dedicated devices,
verify Device Status, and create configuration backups.

## Need help?

Email [droidlink77@gmail.com](mailto:droidlink77@gmail.com?subject=DroidLink%20Help)
