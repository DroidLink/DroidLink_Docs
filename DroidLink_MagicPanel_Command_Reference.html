1. The DroidLink Command Format

:MPT56,10,C2

This is a complete DroidLink MagicPanel command. In timed mode, it means: run pattern 56 for 10 seconds using color 2 (blue).

PartMeaning
:Starts a DroidLink command.
MPRoutes the command to the MagicPanel device type.
T56Runs MagicPanel pattern 56 (Animated Heart).
,10Runs it for 10 seconds.
,C2Uses preset color 2, Blue.
Use the full DroidLink form: commands in this guide begin with :MP. Pattern options are separated with commas. Example: :MPT62,30,C5.

Pattern examples

DroidLink commandResult
:MPT56Run Animated Heart.
:MPT56,10Run Animated Heart for 10 seconds.
:MPT56,C2Run Animated Heart in blue.
:MPT56,10,C2Run Animated Heart for 10 seconds in blue.
:MPT62,30,C5Run Matrix Rain for 30 seconds in cyan.
:MPT109,20,C0Run PSI Random Flicker for 20 seconds in red.
Set timed mode first: send :MPP0 before using a duration. In always-on mode (:MPP1), a continuous pattern such as Animated Heart continues instead of timing out. Duration must be 1–3600 seconds; color must be 0–9.

4. Brightness, Speed, and Mode

DroidLink commandRange / resultExample
:MPB<n>Brightness from 0 to 255.:MPB100
:MPV<n>Animation speed from 1 to 100.:MPV60
:MPSP<n>Alternate speed command, 1 to 100.:MPSP60
:MPP0Timed mode. Required when a continuous pattern should stop after its supplied duration.:MPP0

:MPTRANSITION0Disable smooth transitions.:MPTRANSITION0

High brightness increases current demand. If the panel flickers or resets, reduce brightness and check the power supply.

5. Text Commands

Text may contain up to 48 characters. Saved-text slots are numbered 0–9.

DroidLink commandResult
:MPTEXT:HELLO THEREScroll “HELLO THERE.”
:MPTEXT_BOUNCE:R2-D2Display bouncing “R2-D2” text.
:MPTEXTSAVE0:HELLOSave “HELLO” in slot 0.
:MPTEXTLOAD0Load and scroll the text saved in slot 0.
:MPFONT0Use the standard font.
:MPFONT1Use the Aurebesh font.

6. Saving, Startup, and Information

DroidLink commandResult
:MPSAVESave current panel settings permanently.
:MPLOADReload previously saved settings.
:MPAUTOSAVE0Disable automatic saving.
:MPAUTOSAVE1Enable automatic saving and save current settings.
:MPSTART<n>Set fixed startup pattern n and save it immediately.
:MPSTART0Clear fixed startup pattern; resume the last saved pattern.
:MPSTATUSPrint current brightness, color, mode, speed, font, startup pattern, transitions, autosave, and last pattern to the panel console.
:MPHELPPrint the quick help menu to the panel console.
:MPHELP FULLPrint extended device help to the panel console.
:MPLISTPrint the complete pattern list to the panel console.

7. Recovery Commands

DroidLink commandResult
:MPNEWMACClear the stored Master MAC and reboot into Master MAC setup.
:MPNEWPROFILEClear the matrix profile and reboot into profile selection.
After :MPNEWMAC, DroidLink control cannot resume until the Master MAC is entered again through the panel's USB setup console. Recovery commands should normally be entered directly at the device when its Master connection is unavailable.

Temporary playlist

:MPPLAYLIST_RUN:57,62,109 runs the listed patterns in sequence. Playlist save/load is not implemented.

If a command does not work

  • Confirm it begins with :MP.
  • Do not insert spaces inside pattern commands.
  • Use commas between pattern, seconds, and color: :MPT56,10,C2.
  • Confirm the pattern number exists and is supported by the selected matrix profile.
  • Confirm the MagicPanel is paired with the correct DroidLink Master MAC.
  • Confirm the correct MagicPanel Device ID is configured in the Master.
