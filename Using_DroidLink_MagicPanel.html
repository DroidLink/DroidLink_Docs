MagicPanel
Setup & Install

A simple guide to installing, configuring,
and connecting your MagicPanel
ESP32-C3 • DroidLink Installer • August 2026

1. What You Need

  • Your MagicPanel controller and LED matrix
  • A USB data cable
  • A computer with a compatible browser
  • The DroidLink Installer
  • The Wi-Fi MAC address of your DroidLink Master
Power: use the correct regulated power supply for the LED matrix. Large matrices should not be powered directly from a computer USB port unless the hardware is specifically designed for it.

2. Install the Firmware

  1. Connect the MagicPanel controller to the computer with the USB data cable.
  2. Open DroidLink Installer.
  3. Select the serial/COM port for the ESP32-C3 controller.
  4. Select DroidLink MagicPanel from the firmware list.
  5. Start the installation and approve the browser's serial-port request if prompted.
  6. Wait until the Installer reports that flashing is complete. Do not disconnect the controller during installation.
After installation, open the Installer's Console and set it to 9600 baud.

3. Enter the Master MAC

When the console displays MAGICPANEL FIRST-TIME SETUP, paste the Wi-Fi MAC address of your DroidLink Master and press Enter.

Example format:
9C:13:9E:A8:6F:A8

Use your own Master's MAC address. MagicPanel saves it and immediately continues to Device ID setup.

4. Enter the Device ID

When prompted, enter an unused DroidLink Device ID from 2 through 13.

Example:
12

Master ID 0 and Display ID 1 are reserved. Every configured DroidLink device must have its own unique ID. MagicPanel saves the ID and continues to Matrix Profile setup.

5. Select the Matrix Profile

When prompted, enter the number matching your LED matrix:

EnterMatrix profile
18×15 — 120 LEDs, progressive
28×8 — 64 LEDs, progressive
34×8 — 32 LEDs, serpentine

After the profile is saved, setup is complete and MagicPanel performs one automatic reboot. The normal boot output displays the saved Device ID and Matrix profile.

6. Add MagicPanel to the Master

If the panel has not connected after about 15 seconds, the Console displays Waiting for Master and shows the MagicPanel's own Device MAC.

  1. Copy the displayed MagicPanel Device MAC.
  2. Add that MAC and the chosen Device ID to the DroidLink Master configuration.
  3. Save the Master configuration.
  4. Reboot the DroidLink Master.
Connected: the MagicPanel Console displays DroidLink Connected and MagicPanel Online when communication begins.

7. Quick Test

First select timed mode, then run the test:

:MPP0
:MPT56,10,C2

The MagicPanel should run pattern 56 (Animated Heart) for 10 seconds in blue. In always-on mode (:MPP1), the heart continues instead of timing out.

Status LED and Device Identification

The onboard status LED turns on during first-time setup. During normal operation, press the MagicPanel's matching DEVICE ID button on the Watch Display Settings screen to light the status LED briefly and confirm that the selected device received the identification command.

Normal commands: MagicPanel effect and text commands do not flash the status LED.

Quick Troubleshooting

ProblemCheck
No serial/COM portTry another USB data cable or USB port. Close other programs using the serial port.
No Console outputSelect the correct port and set the Console to 9600 baud. Reconnect or press the controller reset button.
Master MAC rejectedUse six hexadecimal pairs separated by colons: XX:XX:XX:XX:XX:XX.
Waiting for MasterConfirm the correct Master MAC was entered. Add the MagicPanel Device MAC and Device ID to the Master, save, and reboot the Master.
Display looks wrongConfirm that the selected matrix profile matches the connected matrix.
Panel flickers or resetsCheck the power supply, wiring, connectors, and common ground.

Setup Checklist

  • MagicPanel firmware installed through DroidLink Installer
  • Console opened at 9600 baud
  • DroidLink Master MAC saved
  • Unique Device ID saved
  • Correct matrix profile selected
  • MagicPanel Device MAC added to the Master
  • Master configuration saved and Master rebooted
  • Timed mode selected with :MPP0
  • Test command :MPT56,10,C2 completed successfully
